# CryptoAgility Lab

Local crypto-agility and post-quantum migration engineering lab: discover cryptographic dependencies, evaluate explainable policy, test classical/hybrid/PQC compatibility, and produce reproducible migration evidence.

This repository is a local research/engineering prototype, not a production deployment or a claim of organizational PQC compliance. It uses synthetic identities and disposable test keys only.

Implementation is developed through pull requests. No cloud services, proprietary systems, custom cryptographic primitives, or real customer secrets are required.
