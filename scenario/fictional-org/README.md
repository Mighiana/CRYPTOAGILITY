# Fictional organization scenario (synthetic)

Inputs for `cryptoagility lab`: 12 TLS service configurations, 2 legacy client configurations and,
generated at run time, 7 RSA certificates, 3 ECDSA certificates and 1 ML-DSA-65 pilot certificate.
Every name uses the reserved `.test` domain. No real system, organization or key is represented;
private keys are generated in a temporary directory and deleted before scanning.
